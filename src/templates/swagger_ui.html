# Listar todos os artigos de 2026

Sobre o Projeto

dataWASHES é uma iniciativa colaborativa, open-source e sem fins lucrativos

💡

Motivação

Dada a importância do WASHES no panorama de pesquisa brasileira de Engenharia de Software, existe uma oportunidade de criar uma infraestrutura aberta para facilitar o acesso aos seus dados. Com um extenso acervo de artigos publicados ao longo de mais de uma década, o processo manual de acesso torna-se ineficiente para quem deseja conduzir estudos secundários ou análises robustas.

🛠

Proposta

Apresentamos o dataWASHES, uma API pública, acadêmica e open source, projetada para facilitar o acesso programático aos anais do WASHES disponíveis na SBC OpenLib (SOL). Nossa meta é oferecer à comunidade uma ferramenta para acessar sistematicamente e programaticamente dados de papers, autores e edições.

📚

Referências

Os anais do WASHES estão disponíveis na SBC OpenLib (SOL). Todos os documentos publicados são disponibilizados sob a licença Creative Commons (CC BY 4.0), permitindo cópia e redistribuição em qualquer meio ou formato. O desenvolvimento é colaborativo sob MIT License.
